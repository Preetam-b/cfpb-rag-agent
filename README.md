# CFPB Consumer Complaint Assistant

An autonomous agentic RAG system that classifies a consumer financial complaint,
researches the relevant regulations, assesses risk/fraud, and drafts a formal
dispute letter or plain-language guidance -- with a human in the loop at every
consequential decision.

See the full project writeup in `PROJECT.MD`.
